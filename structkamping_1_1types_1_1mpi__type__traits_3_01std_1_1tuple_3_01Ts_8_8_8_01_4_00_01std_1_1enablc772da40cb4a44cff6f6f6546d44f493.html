Detailed Description

template<typename... Ts>
struct kamping::types::mpi_type_traits< std::tuple< Ts... >, std::enable_if_t<(has_static_type_v< Ts > &&...)> >

Specialization of kamping::types::mpi_type_traits for std::tuple, representing the tuple as an MPI struct type derived from its element types.

Specialization of kamping::types::mpi_type_traits for std::tuple, representing the tuple as a flat sequence of sizeof(std::tuple<Ts...>) bytes using MPI_BYTE.

All element types must already have a static MPI type (i.e. kamping::types::has_static_type_v must be true for every element type). The resulting MPI datatype correctly reflects the memory layout, including any padding inserted by the compiler.

Note
This header and kamping/types/std/unsafe/tuple.hpp provide conflicting specializations — include only one.
For maximum throughput at the cost of correctness guarantees, use the byte-serialized variant in kamping/types/std/unsafe/tuple.hpp instead.

All element types must already have a static MPI type (i.e. kamping::types::has_static_type_v must be true for every element type).

Warning
This serialization ignores any padding bytes the compiler may insert between or after elements. Sending a padded tuple is only correct when both sides share the same ABI. For a layout-safe alternative use kamping/types/std/tuple.hpp.
